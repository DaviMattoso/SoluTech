Dia 1

E VAMOS PARA MAIS UM DIARIO DE UM DEV
Esse projeto é um comeco de algo muito grande, to trabalhando com 5 craneos que mano... bagulho doido, isso é um projeto de uma empresa que cria solucoes para pessoas e empresas, tudo isso com base em tecnologia e infomacao, foda pra krl
Como manjo mais de web fiquei com o site e tambem pra ver sobre o sistema do primeiro projeto, mas isso é historia pra outro diario.
A proxima reu é domingo e queria ter pelo menos uma base pra mostrar o site da empresa e oque da pra fazer referente ao sistema, tamo vendo isso ai ainda
Como sempre cheguei MOIDO do job e minhas costas tao querendo sair do corpo já, mas o bagulho é doido e minha cadeira confortavel XD

Comecei pela estrutura geral da página. Mantive o HTML dividido em seções para facilitar a organização e a navegação entre as partes do site. O Header ficou responsável pela navegação principal, depois vieram o Hero, Soluções, Pessoas e Empresas, Sobre Nós, Contato e, por último, o Footer. Também deixei os IDs das seções para conseguir navegar pela página através dos links do menu. optei nao cirar paginas e mais paginas externas dentro do projeto para cada sessão, entao vai ficar tudo na pagina principal, ou pelo menos até agora vai. No CSS comecei organizando as cores principais em variáveis. Isso acabou ajudando bastante durante o desenvolvimento, porque praticamente toda a identidade visual passou a depender dessas variáveis. O azul principal da empresa ficou como #1268ff, enquanto o azul escuro utilizado como fundo ficou em #061426 e o texto principal em #101a2b.

}

Depois fui trabalhar no Header. Queria que ele tivesse uma aparência mais tecnológica e profissional, então deixei ele fixo no topo, com fundo escuro e um pouco de transparência. Também usei backdrop-filter para criar aquele efeito de vidro quando a página passa por baixo do Header.

.header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 75px;
    z-index: 1000;


    background: rgba(3, 16, 31, 0.92);
    backdrop-filter: blur(12px);
}

Depois veio o Hero, que acabou sendo uma das partes que mais exigiu ajustes. A ideia inicial era ter a imagem de um lado e o texto do outro, mas depois achei muito mais interessante fazer a imagem ocupar toda a área e colocar o conteúdo por cima dela. Isso deixou a imagem muito mais presente e deu uma aparência mais próxima de um site profissional de tecnologia.

No CSS coloquei a imagem ocupando toda a seção com position: absolute, object-fit: cover e object-position: center top. O center top foi importante porque a parte superior da imagem estava sendo cortada e eu queria manter visíveis os elementos que estavam naquela região.

.hero-image {
    position: absolute;
    inset: 0;


    width: 100%;
    height: 100%;


    overflow: hidden;
    z-index: 1;
}


.hero-image img {
    width: 100%;
    height: 100%;


    object-fit: cover;
    object-position: center top;
}

Como o texto precisava ficar legível sobre a imagem, criei uma camada de degradê escura. Ela começa bem mais forte do lado esquerdo, onde está o conteúdo, e vai ficando transparente em direção à direita.

.hero-image::after {
    content: "";


    position: absolute;
    inset: 0;


    background:
        linear-gradient(
            90deg,
            rgba(3, 12, 24, 0.94) 0%,
            rgba(3, 12, 24, 0.78) 24%,
            rgba(3, 12, 24, 0.40) 48%,
            rgba(3, 12, 24, 0.10) 75%,
            rgba(3, 12, 24, 0.02) 100%
        );


    z-index: 2;
}

Também precisei trabalhar nos espaçamentos do conteúdo. Os botões estavam muito próximos do texto e um do outro, então aumentei o espaço entre eles e deixei os próprios botões um pouco maiores.

Uma das mudanças que mais gostei foi o comportamento dos cards. Em vez de fazer aquele hover padrão onde o card simplesmente sobe alguns pixels, decidi fazer o card inteiro mudar para o azul escuro da SoluTech. Quando o mouse entra, o conteúdo desaparece e o botão "Saiba mais →" aparece centralizado.

.card:hover {

A estrutura do contato foi feita em duas colunas no desktop, deixando o conteúdo do formulário de um lado e uma área maior do outro.

Foi nessa parte que surgiu a ideia do mascote da SoluTech. Em vez de colocar novamente fotos de membros da equipe, achei que seria mais interessante colocar um personagem representando a empresa e convidando o usuário para conversar.

No HTML, a imagem ficou dentro de um bloco próprio:

<div class="contact-mascot">
    <img
        src="img/Mascote ct.png"
        alt="Assistente SoluTech"
    >
</div>

Depois ajustei o CSS para a imagem não ficar esticada. Inicialmente ela estava ocupando toda a altura do container e parecia uma imagem quadrada. Troquei para height: auto, mantive object-fit: contain e coloquei bordas arredondadas.

.contact-mascot {
    position: relative;


    width: 100%;
    height: 600px;


    display: flex;
    align-items: center;
    justify-content: center;


    overflow: hidden;
}


.contact-mascot img {
    width: 100%;
    max-width: 520px;


    height: auto;


    object-fit: contain;
    object-position: center;


    border-radius: 40px;


    display: block;


    transition: transform 0.4s ease;
}


.contact-mascot:hover img {
    transform: scale(1.02);
}

Esse pequeno efeito de escala acabou deixando a imagem mais viva sem exagerar na animação.

Depois fui para a parte de responsividade. Eu já tinha deixado a estrutura preparada para 1024px e 600px, mas precisei ajustar cada seção para não quebrar quando a largura diminuísse. No tablet, os quatro cards de soluções passam para duas colunas, enquanto no celular passam para uma coluna.

@media (max-width: 1024px) {


    .cards-grid {
        grid-template-columns: repeat(2, 1fr);
    }


    .card {
        min-height: 195px;
    }


}

No celular, a estrutura muda novamente:

@media (max-width: 600px) {


    .cards-grid {
        grid-template-columns: 1fr;
        gap: 12px;
    }


    .audience-grid {
        grid-template-columns: 1fr;
    }


    .about-container {
        grid-template-columns: 1fr;
    }


    .contact-container {
        grid-template-columns: 1fr;
        gap: 35px;
    }


}

No final da sessão também deixei o Footer organizado com as áreas de Soluções, Empresa, Suporte e Contato, além dos links de redes sociais e copyright.

Depois de todas essas alterações, a página já começou a parecer muito mais com uma empresa de verdade e menos com uma estrutura inicial de teste. Ainda existem algumas partes que são apenas visuais, principalmente os botões e o formulário, mas a identidade da SoluTech está praticamente definida.

O mais interessante dessa sessão foi que várias coisas foram surgindo enquanto eu desenvolvia. O Hero mudou de estrutura, os cards ganharam um hover diferente, a seção de contato ganhou o mascote e a própria proposta da empresa foi ficando mais clara conforme eu montava o conteúdo. No final, foram aproximadamente 4 horas de desenvolvimento, testes e ajustes, e agora a base visual está pronta para começar a receber as funcionalidades.

Próxima sessão

A próxima etapa já deve sair um pouco da parte puramente visual e começar a colocar funcionalidades no projeto.

A primeira ideia é criar o chatbot da SoluTech, fazendo com que o botão "Fale Conosco" do Header possa abrir o atendimento e colocando também um botão flutuante do assistente no canto da tela. A ideia é que o mascote apresentado na seção de contato não seja apenas uma imagem bonita, mas esteja relacionado ao próprio assistente IA.

Também quero criar o favicon oficial da SoluTech, usando a identidade visual da empresa para que o site tenha sua própria identificação na aba do navegador.

Por último, falta finalizar o menu mobile. O CSS já possui a estrutura para o menu aparecer através da classe .open, então a próxima etapa será criar o botão no Header e fazer o JavaScript controlar a abertura e fechamento das opções de navegação.
