## Como o site foi feito

Uma página só, dividida nas mesmas ideias da empresa: início, soluções, públicos, sobre, cases e contato.

| Arquivo | Função |
| --- | --- |
| `index.html` | Página: texto, seções e metadados |
| `404.html` | Resposta quando o endereço não existe |
| `css/style.css` | Visual, layout responsivo e temas claro e escuro |
| `js/theme-init.js` | Aplica o tema salvo antes da primeira pintura |
| `js/script.js` | Menu, troca de tema, slides de trabalhos e formulário |
| `img/` | Logo, banner e imagens dos públicos |
| `robots.txt` | Permissão de rastreamento e endereço do sitemap |
| `sitemap.xml` | Mapa do site para os buscadores |
| `.htaccess` | HTTPS, cache e cabeçalhos de segurança no Apache |

O formulário de contato envia a mensagem pelo [Web3Forms](https://web3forms.com), com verificação hCaptcha. A escolha de tema fica salva no navegador.
